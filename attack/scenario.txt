Project 10 — Multi‑Stage Attack Scenario

1. Recon
Attacker profiles finance volunteers and learns communication patterns.

2. Delivery
Attacker sends a phishing email and a deepfake video call to the volunteer.

3. Credential Harvest
Volunteer enters credentials into a fake login portal created by the attacker.

4. Exploitation
Attacker uses stolen credentials from Romania (impossible‑travel login).

5. Privilege Escalation
Attacker performs sudo without a change ticket.

6. Lateral Movement
Attacker SSHes into db1 from an international IP.

7. Collection
Attacker performs bulk donor‑table SELECT operations.

8. Exfiltration
Attacker curls data to an external attacker‑controlled IP.

9. Indirect Prompt Injection
Attacker submits a fake “reset my account” request. The help‑desk assistant retrieves rag_notes.txt and reads the hidden SYSTEM NOTE instructing it to export the donor table.

10. AI Abuse
The help‑desk assistant obeys the poisoned instruction and automatically exports the donor table to https://203.0.113.55/u, completing a second exfiltration path.
